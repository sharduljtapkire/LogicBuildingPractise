# Java Programming Collection (Program1–Program665)

## Overview

This repository contains an extensive collection of **665 Java programs** developed by **Shardul Tapkire**, showcasing progressive learning of Java programming concepts from beginner to advanced. Topics include syntax, object-oriented programming, data structures, algorithms, file systems, mathematical computing, bitwise operations, and system-level programming.

The programs are organized into categories that mirror a structured learning progression.

## Learning Progression

  * **Beginner (Programs 1–100):** Control structures, arrays, basic I/O
  * **Intermediate (Programs 101–300):** Strings, files, OOP, algorithms
  * **Advanced (Programs 301–633):** Data structures, system programming, IP & bitwise operations, encryption, custom file systems
  * **Expert / Generic Implementations & Applications (Programs 634–665):** Generic Data Structures, combined utilities, **Built-in Collections**, **Serialization**, and **Custom DBMS Implementation**.

-----

## Technical Skills Covered

  * **Core Java:** Syntax, OOP (Classes, Static, `toString`), **Generics**, Exception Handling, **Serialization/Deserialization**
  * **Data Structures:** Arrays, Linked Lists (Custom and **Built-in `java.util.LinkedList`**), Stacks, Queues, Trees, Graphs, Circular/Linear Linked Lists
  * **Algorithms:** Sorting, Searching, Dynamic Programming, Number property checks
  * **File I/O:** Stream handling, virtual file systems, encryption/decryption, **Object Streams**
  * **System Programming:** Command execution, shells, **In-memory Database Simulation**
  * **Mathematical & Bitwise Computing:** Bit manipulation, number theory, encryption techniques

-----

## Usage

Each program is standalone and can be compiled and executed individually:

```bash
javac ProgramX.java
java ProgramX
```

Replace `X` with the program number (e.g., `Program665.java`).
